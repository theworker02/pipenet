# pipenet

Pipe validation gates for net inputs before they hit prod.

**Site:** https://theworker02.github.io/pipenet/

## Install / run

```bash
git clone https://github.com/theworker02/pipenet.git
cd pipenet
node src/cli.js
node --test
```
